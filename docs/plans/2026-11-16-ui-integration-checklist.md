## □ 통합 중 깨지기 쉬운 장치

○ 화면 타이머 쉬기 (D134)
  - 「최종 편집」 탭이 앞이면 타이머 셋(1초 상태 · 2초 그리기 · 2초 알림)이 쉼
  - 탭 구조를 바꾸면 `_wire_timer_rest` 연결을 다시 봐야 함
○ 타임라인 렌더 끝 알림 (W-71h)
  - 타이머가 쉬는 동안 재생기가 `tl_job`으로 렌더를 물어 끝나면 숨은 「다시 열기」를 누름
  - 숨은 단추 이름이나 자리를 바꾸면 이 길이 끊김
○ 패널 칸은 고른 영상만 실음 (D122)
  - 새 칸을 더할 때 다른 영상의 상세를 싣지 않아야 함
  - `tests/raw/test_render_cost.py`의 payload 바이트 상한이 지킴
○ 로컬 미디어 자리 우선순위 (D136·D140)
  - 썸네일·원본 전체 미리보기·렌더·번인은 급한 자리, 미리 만드는 분석 프록시만 보통 자리
  - 새 로컬 ffmpeg 일을 더하면 `media_refs.local_media_slot(urgent=…)`를 정해야 함
○ 카드 썸네일 (D133)
  - 그림 요청은 ETag로 304, 카드 `<img>`는 `loading="lazy"`
  - 카드 그리기를 다시 짜면 두 속성이 남아 있어야 함
