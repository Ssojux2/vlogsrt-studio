# 측정 대시보드

`make eval`이 아래 표를 갱신한다. 표 바깥의 글은 건드리지 않는다.

측정 대상은 `eval/<변형>/<회차>.srt`이고 정답은 `golden/<회차>.srt`다.

| 변형 | 뜻 |
|---|---|
| `b0` | 골격 큐 그대로 (`--stop-after refine` 전 단계와 비교용) |
| `b1` | 정제 엔진까지 (`--stop-after refine`) |
| `full` | 최종 출력 (`vlogsrt run`, 검증 포함) |
| `fast` | `--fast` (word 타임스탬프 없음) |

<!-- vlogsrt:dashboard -->

|---|---|---|---|---|---|---|---|---|

## 관문

| 관문 | 조건 | 상태 |
|---|---|---|
| 1 (T2.7) | 큐 경계 F1 > 0.80, 위반율 < 2% | 미측정 — 골든셋 필요 |
| 2 (T3.8) | B1 대비 CER 절반 이하 **이면서** MAE·적중률 ±5% 이내 | 미측정 — 골든셋 필요 |
| 3 (T4.3) | 고유명사 정확도 > 95% | 미측정 — 사전 재녹화 필요 |
| 최종 (T5.5) | 검토 시간 < 영상 길이 × 0.3 | 미측정 — 실사용 필요 |

측정하려면 `golden/ep0{1,2,3}.{mp4,srt}`와 `tests/fixtures/api/ep0*.{whisper,gpt,meta}.json`이
있어야 한다. 둘 다 사람이 만든다.
