## 1단계 — 재녹화 (유료)

```bash
vlogsrt record <영상>
```

□ whisper와 gpt를 함께 받는다. 현재 설정(조각 180초)으로 녹화된다
□ 비용: 77분 기준 약 **$0.92**. 근거는 분당 $0.012
□ 되풀이가 있으면 `rescue`·`arbiter` 응답이 더 녹화된다. 추가분은 되풀이 구간 길이에만 붙는다
□ 첫 줄을 확인한다 — `조각 26개 · 가장 긴 조각 3.0분`이어야 한다
  ○ 아니면 설정이 안 닿은 것이다(D27의 재발)

---

## 2단계 — 오프라인 재실행 (무료)

```bash
vlogsrt run <영상> --out out/<회차> --offline
```

□ 1단계가 만든 픽스처를 읽는다. **추가 비용이 없다**
□ 새 `trace.json`이 나온다. 이것이 3단계의 입력이다

---

## 3단계 — 시각 대조 (무료)

```bash
python scripts/verify_timing.py <회차> --out out/<회차>
```

□ `make`는 쓰지 마라. 이 머신의 `make`는 Xcode 라이선스로 죽어 있다
□ 지금 `out/fr_day_3/trace.json`은 버전 9.0이라 이 스크립트가 종료 1로 죽는다.
  Q3-1이 10.0으로 올렸다. **2단계가 만든 새 트레이스로는 돈다**
