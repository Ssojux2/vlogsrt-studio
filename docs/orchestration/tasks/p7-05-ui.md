## Contract

```python

    status: str
    log: str
    workspace: str
    result_paths: tuple[str, ...]
    needs_analysis: tuple[str, ...] = ()

def stream_project(input_path: str, workspace: str, output_dir: str, action: Literal["inspect", "analyze", "plan", "export", "captions", "run"], authorize_online: bool = False) -> Iterator[ProjectUiReport]: ...
```

- Add a separate lightweight project section: local FCPXML/bundle path, workspace/output path, action, explicit online authorization for analyze/run, status/log, result paths.
- No browser video upload/copy, full NLE, timeline editor, embedded video, or mandatory hand-edited JSON. Native/local path input remains.
- `ui.service` imports and calls only the narrow public `vlogsrt.cli.run_project_action` bridge added by P7-03. It must not import `vlogsrt.project`, duplicate edit/analysis logic, or invoke the CLI through a subprocess. Offline actions hard-disable network.
- Errors are concise/sanitized, draft/unresolved and needs_analysis are visible; never show final acceptance when pending.
- Existing Gradio subtitle path/UI behavior and tests remain unchanged.
