**시그니처 충분성:**

2. **`Segment`에 조각 번호가 없다**(`vlogsrt/models.py:31-46`). §4-1은 "그 조각 시간 범위의 spine 세그먼트"를 `start`와 `offset` 비교로 **다시 유도**해야 한다. 정확한 값(어느 응답에서 온 세그먼트인가)은 `transcribe.parse_segments`(`transcribe.py:466`)에서 이미 버려진다. 지금은 `start = seg.start + offset ≥ offset`이라 대체로 맞는다. 하지만 이것이 P4-04 모양이다. 재전사로 갈아끼운 세그먼트는 다른 조각 체계(`cut_spans`)에서 오기 때문이다. 권고: 출처(`chunk_index` 또는 `rescued`)를 세그먼트나 settle 결과에 실어 나른다.
